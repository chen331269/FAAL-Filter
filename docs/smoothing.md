# 平滑是怎么工作的

这篇解释代码里那条"平滑链路"到底在做什么。不需要线性代数，跟着数字走一遍就行。

## 一句话

> 把输入按大小拆开：大的立刻送走，小的才进滤波器。

这样既不会被手抖拖慢，也不会在正常动作时加延迟。

---

## 1. FAAL 里的三层

| 层 | 管什么 | 在哪 |
|---|---|---|
| **抑制** | 这一刻该压多少（峰值、衰减、冻结、过零、反转） | `doFilter` 前 12 步 |
| **分层** | 输入怎么在"平滑"和"直通"之间分配 | `smoothTierWeight` |
| **低通** | 进滤波的那部分有多顺 | `oneEuroWithCutoff` |

抑制全部基于**原始输入**，和后面两层无关。所以调平滑不会改变抑制的触发条件。

---

## 2. 每帧的流程

```
            ┌─→ smoothTierWeight(speed) ──→ w ──→ 拆输入
speed = |V| ─┤
            └─→ fc = fc_min + beta·speed ──→ 一阶低通 ──→ 平滑输出

out = V·w + 平滑输出
out *= (1 − 抑制量)
```

对应代码：

```cpp
// ① 入口，整帧算一次
float speed = sqrtf(x*x + y*y);        // 向量速度，deg/s
float w = smoothTierWeight(speed);      // 0..1

// ② 逐轴
float fc = fc_min + beta * speed;                    // Hz
float smoothed = oneEuroWithCutoff(v * (1-w), dt, fc, state);

// ③ 合并
out = v*w + smoothed;
```

注意 `speed` 是**整个向量的长度**，不是单个轴。两个轴用它算出的 `w` 和 `fc` 完全相同——这是方向不变形的前提。

---

## 3. 三个速度下的实际行为

设 `smoothThreshold = 4`（则 T1 = 2，T2 = 4）。

### 静止：1°/s，w = 0

```
直通 = 1 × 0    = 0
平滑 = 1 × 1    = 1  → 全部进低通
```

输出完全由低通决定，手抖被压掉。

### 中速：3°/s，w = 0.5

```
直通 = 3 × 0.5  = 1.5   ← 立刻出去
平滑 = 3 × 0.5  = 1.5   ← 慢爬，约 70 ms 到齐
```

一半即时、一半延迟。

### 快：5°/s 以上，w = 1

```
直通 = 5 × 1    = 5     ← 立刻
平滑 = 5 × 0    = 0     ← 低通被喂 0，状态自然排空
```

**零延迟**，滤波器完全不参与。

---

## 4. 为什么是"拆输入"而不是"混合输出"

直观写法可能是：

```cpp
out = smooth(v) * (1-w) + v * w;      // ❌ 不要这样
```

它有两个问题：

**① 丢位移**
大动作时 `w=1`，`smooth` 那份被乘 0——缓冲里还没消费完的量直接丢弃。玩家转了 100°，实际只转了 70°。

**② 状态污染**
大动作时整个 100 都进了滤波器。哪怕这帧被乘没了，接下来 `w` 回落，那个 100 会从状态里冒出来，变成过冲。

拆输入就没有这两个问题：**进滤波器的永远只有慢的那部分**，它迟早会被消费完，总量守恒。

---

## 4½. 为什么速度要先低通

`w` 和 `fc` 都读同一个速度。如果读瞬时值，抖动会让 `w` 跟着一起摆：

```
out = v·w + smoothed        ← w 在抖，v·w 这一项就带上了抖动频率
```

于是输出不但没被平滑，反而可能比输入还抖（实测 6 dps 平台上，间歇值从 1.06 放大到
1.39 dps）。给速度加一个 ~30 ms 的低通后，同一工况降到 0.57 dps，而大动作的响应只从
4 ms 变成 8 ms。所以 `speedLpMs` 默认 30，且通常不需要改。

## 5. 为什么两轴共用一个 fc

如果每轴自己算 `fc = fc_min + beta·|本轴速度|`：

```
x 轴快 → fc_x 大 → 滞后小
y 轴慢 → fc_y 小 → 滞后大
```

结果 x 轴超前、y 轴滞后，**画圆会变成椭圆**，方向被拉偏。

所以 `fc` 由入口按向量速度算一次，两轴共用。整个平滑层就是"对向量做各向同性的低通"。

---

## 6. 参数

| 参数 | 默认 | 作用 |
|---|---|---|
| `smoothThreshold` | 0 | 分层阈值。**0 = 自动推导（5 × fc_min）**；负值 = 完全不平滑；正值 = 显式指定。平时不需要动它，缩放会跟着 `fc_min` 走 |
| `speedLpMs` | 30 | 速度低通（ms）。`w` 和 `fc` 都用低通后的速度；0 = 关闭 |
| `oneEuroFcMin` | 2.0 | 截止频率下限（Hz）。越小越顺、越滞后 |
| `oneEuroBeta` | 0.08 | 速度反馈系数。越大，动得越快越少平滑 |

三者的分工：

- `smoothThreshold` 决定**要不要平滑**（开关 + 分段），留 0 时随 `fc_min` 自动缩放
- `fc_min` 决定**最慢时平滑得多狠**
- `beta` 决定**带内速度越快、放松得多快**

---

## 7. 和标准 One Euro 的差异

标准版有三个部分：

```
dx     = (x - x_raw_prev) / dt      ← 用原始输入算导数
dx_hat = 低通(dx, d_cutoff)          ← 导数再低通一次
fc     = fc_min + beta·|dx_hat|
x_hat  = 低通(x, fc)
```

本实现：

| 部分 | 标准 | 本实现 |
|---|---|---|
| 导数来源 | 原始输入 | 调用方用向量速度代替 |
| 导数低通 | 有 | **无**（`alpha_d = 1`） |
| 信号低通 | 有 | 有 ✅ |
| fc 来源 | 每轴自算 | **调用方统一给** |

少了导数低通，意味着噪声尖峰可能短暂抬高 `fc`，让一帧的噪声透过去。分层平滑在很大程度上抵消了这一点——真正的高频抖动都在低阈值段被拦住了。

---

## 8. 怎么调

1. 先把 `smoothThreshold` 设成负数（纯抑制，不平滑），确认抑制本身的手感
2. 逐步调大：`4 → 8 → 15 → 30`，每次只改这一个
3. 找到"静止不抖、动作跟手"的那个点

经验值：手抖一般在 1~3°/s，正常瞄准在 5°/s 以上。**阈值落在两者之间**就对了。

如果低速段觉得"太活"，降低 `beta`；如果觉得静止还不够稳，降低 `fc_min`。
