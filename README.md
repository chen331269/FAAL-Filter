# FAAL Filter (Frame-rate Adaptive Attenuation Layer)

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![C++](https://img.shields.io/badge/language-C++-orange.svg)

**FAAL** 是一个为体感瞄准（陀螺仪瞄准）设计的轻量级、帧率无关、自适应去抖滤波器。单头文件实现，无外部依赖，可直接嵌入你的 C/C++ 项目。

---

## 🛑 你遇到过这些问题吗？

用体感玩游戏或用体感设备时，手感总是不对：
*   **静止时准星微微飘** —— 手没动，准星在晃。
*   **甩枪后有回弹** —— 快速甩动停下来，准星会“弹回来”一点。
*   **按键时抖动** —— 按下扳机那一刻，瞄准突然偏了。
*   **换手柄就废** —— 换了个回报率不同的手柄，之前调好的参数全废了。

市面上的滤波器要么平滑了但延迟大，要么跟手了但抖。**FAAL 就是为了同时解决这四个问题而生的。**

---

## ✨ 核心特性

*   🎯 **帧率无关 (Frame-rate Independent)**：所有时间常数都归一化到 1000Hz 基准。60Hz、125Hz、1000Hz 设备上表现完全一致，换设备无需重新调参。
*   🧠 **自适应减速抑制**：甩枪后自动进入“黏滞”模式防回弹，正常跟随时自动进入“跟手”模式，无阈值跳变。
*   🌊 **One Euro 平滑**：借鉴 Casiez 2012 的经典算法，静止时稳如泰山，快速移动时毫无拖影。
*   🌀 **三维矢量反转检测**：替代传统的分轴符号翻转，防止画圆时轨迹变成方形。

---

## 🔬 工作原理

FAAL 就像一个有经验的摄影师助手：
*   当你**静止不动**时，他帮你稳住三脚架。
*   当你**缓慢转动**时，他松手让你自由微调。
*   当你**快速甩动**时，他跟着你快速移动。
*   当你**突然停下来**时，他立刻扶稳设备防回弹。

### 核心创新：抑制强度自己决定释放速度
大多数滤波器的滞回时间是固定的。FAAL 不一样：
*   **抑制弱**（正常跟随） -> 释放快 -> **跟手**
*   **抑制强**（甩枪刚结束） -> 释放慢 -> **黏滞保抑制**

## 🚀 快速开始

只需要将 `faal_filter.h` 和 `faal_filter.cpp` 加入你的工程。

### 1. 初始化参数
```cpp
#include "faal_filter.h"

// 初始化参数（推荐先用默认值）
FaalParams p;
p.hystFallTime    = 0.065f;   // 抑制慢出上限 (秒)
p.oneEuroFcMin    = 2.0f;     // 静止平滑度
p.oneEuroBeta     = 0.08f;    // 快速跟随度
p.signChangeThr   = 0.5f;     // 符号翻转防抖灵敏度
SetFaalParams(p);
